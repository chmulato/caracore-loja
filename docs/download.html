Verificação de Integridade SHA256

Para garantir que o arquivo baixado não foi corrompido ou adulterado, abra seu terminal e compare o hash calculado com o hash oficial informado no catálogo:

No Windows (PowerShell):
Get-FileHash -Algorithm SHA256 "C:\Caminho\arquivo.zip"
No Linux / macOS (Terminal Bash):
sha256sum arquivo.zip

Se o hash retornado pelo comando for idêntico ao exibido no card da aplicação, o binário é autêntico e seguro para execução.
