Como instalar

Escolha o card pelo status e confira o SHA256 antes de abrir o arquivo. O caminho é o mesmo para todos os produtos desktop.

  1. Abra o card do produto e leia o status: estável, piloto ou preview.
  2. Baixe o pacote da plataforma em que você vai usar.
  3. Confira o SHA256 do arquivo baixado com as instruções de verificação de integridade.
  4. Extraia o ZIP ou execute o instalador em uma pasta com permissão de escrita. Quando o card exigir JDK 25, instale o Java antes de abrir.
  5. Produto de acesso online, como o CSO Frotas, não tem instalador: entre pelo navegador com a conta da empresa.

O passo a passo de cada produto está na wiki e na loja do produto, ambas ligadas no card.

Como verificar o SHA256

Cada card do catálogo publica o SHA256 do arquivo. Baixe o pacote, calcule o hash no seu computador e compare com o valor publicado no card: se os dois forem iguais, o arquivo corresponde ao digest informado.

Windows (PowerShell)

Get-FileHash -Algorithm SHA256 "C:\Caminho\arquivo.zip"

Windows (Prompt de Comando)

certutil -hashfile "C:\Caminho\arquivo.zip" SHA256

Linux / macOS (terminal Bash)

sha256sum arquivo.zip

Os instaladores publicados hoje não têm assinatura digital. O SHA256 confere a integridade do download, não a origem do arquivo nem a segurança do conteúdo.

Por que o modelo Bunker Digital?

Acreditamos que pequenas e médias empresas não devem ser reféns de instabilidades de internet, quedas de servidores em nuvem ou custos recorrentes abusivos.

Dados Soberanos

Seus bancos de dados (SQLite/arquivos locais) residem no seu computador ou servidor local. Você tem posse real dos seus registros.

Operação Ininterrupta

O PDV Java Free é uma aplicação web local e mantém os dados no computador. Cada produto informa no card se exige acesso à internet; não presumimos sincronização em nuvem.

Transparência Radical

O que está pronto é distribuído. O que está em desenvolvimento é claramente rotulado. Sem surpresas nem falsas promessas.

Integridade verificável

Nenhum instalador desta central tem assinatura digital hoje. Cada card publica o SHA256, e a verificação mostra como conferir no Windows, no Linux e no macOS, sem pedir para desativar SmartScreen ou antivírus.

Verificação de Integridade SHA256

Para garantir que o arquivo baixado não foi corrompido ou adulterado, abra seu terminal e compare o hash calculado com o hash oficial informado no catálogo:

No Windows (PowerShell):
Get-FileHash -Algorithm SHA256 "C:\Caminho\arquivo.zip"
No Windows (Prompt de Comando):
certutil -hashfile "C:\Caminho\arquivo.zip" SHA256
No Linux / macOS (Terminal Bash):
sha256sum arquivo.zip

Se o hash calculado for igual ao SHA256 publicado, o arquivo corresponde ao digest informado. Isso não substitui a conferência da origem nem uma avaliação de segurança.
