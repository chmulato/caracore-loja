Como ler as ligações

O que a árvore mostra

O ramo é o problema de negócio. O produto é a ferramenta publicada para esse problema. PDV Java, PDV v4 e PDV Rust são três linhas de caixa.

Onde o dado fica

PDV, Ink, Hub desktop e o piloto Rust usam banco no computador. CSO Frotas é o produto web. Os canais do Hub exigem internet e credencial do marketplace.

Vitrines fora do arquivo

MKT é vitrine gratuita. Helianto é vitrine, com GA em 30/12/2029. O Seed aparece no catálogo como piloto público para avaliação, ainda não homologado.
